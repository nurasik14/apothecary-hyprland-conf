# Application theming (app-theming)

> **Theme system, switchable.** Apothecary Hyprland is a theme system layered on top of the JaKooLit
> Hyprland dotfiles, not a replacement for them. Turn it on with `apothecary on` and off with `apothecary off`
> (the stock desktop returns in about 5 s, no logout); `apothecary status` shows which state is active.
> `apothecary off` runs `apps/apply-mode.sh off`, which puts your pre-theme app settings back. How the switch works: [README](../README.md#a-theme-system-you-can-switch-on-and-off).

Everything the user runs outside the Quickshell shell, themed for both modes and switchable live.

```
apps/install.sh            install theme files, backups, marker lines, `current` symlinks (LIGHT). Changes NO gsettings.
apps/apply-mode.sh <m>     light | dark | off — flips every ~/.config/apothecary/<app>/current* symlink, gsettings,
                           sed'd keys, kitty reload. `off` = user's pre-theme values back (apps-state.json).
apps/uninstall.sh          apply-mode off, then moves every `.pre-apothecary` backup back, strips markers, removes files.
apps/lib.sh                shared helpers (state json, backup_file, replace_with_symlink, append_marker, set_kv/restore_kv).
```

State: `~/.config/apothecary/apps-state.json` (pre-theme gsettings, pre-theme key values, lists of backups / markers /
created files), `~/.config/apothecary/apps-mode` (last applied: light|dark|off). The `apothecary light|dark` CLI
(hyprland-engineer) calls `apps/apply-mode.sh <mode>`.

Rules applied to every user file: never edited in place without a `<file>.pre-apothecary` backup (never overwritten);
marker lines carry `apothecary` (`# apothecary`, `/* apothecary */`, `// apothecary`, or the `~/.config/apothecary/…`
path itself); whole-file replacement is a symlink → `~/.config/apothecary/<app>/current*`; in `off` mode those
symlinks point at the backup, so the user's file content is exactly what it was.

## Gaps / follow-ups

- Running GTK apps (Thunar daemon) need a restart to pick up `gtk.css`; `apply-mode.sh` deliberately restarts nothing.
- Qt apps re-read qt6ct/Kvantum on launch only.
- tokens `fastfetch-colors.jsonc` uses renamed keys (`display.bar.charElapsed` → `display.bar.char.elapsed`, `borderLeft` → `border.left`) — fastfetch 2.68 refuses the file; noted in REQUESTS.md. The app configs here inline the corrected block.
- Papirus folder colour (teal) not done (`papirus-folders` absent; would require copying Papirus to `~/.local/share/icons`).
