# Apothecary Hyprland — Design System (v1)

Owner: design-director. Source of truth for colour/type/space/motion is `tokens/tokens.json`; everything in this
document that is a number is also in that file. Generated per-app files live in `tokens/out/<mode>/`
(`python3 tokens/build.py`). Textures/seals are generated by `tokens/make-textures.sh`. QML foundation is
`quickshell/Common/`. Preview: `source scripts/dev-env.sh && qs -p quickshell/Common/preview`.

Screenshots of the preview (both modes): `qa/screenshots/design-preview-light.png`, `qa/screenshots/design-preview-dark.png`.

## 1. Concept and signature gesture

**Premise.** The desktop is Maomao's workbench in the Rear Palace. Every surface is an object from that world:

| UI thing | world object | how it shows |
|---|---|---|
| desktop widget | a framed, mounted sheet of rice paper | `PaperPanel`: paper fill + grain, 2 px ink frame, 1 px inner hairline (scroll-mount double rule), lacquer title strip |
| panel / launcher | a lacquered medicine cabinet | wood fronts, labelled drawers, brass ring pulls, paper ground inside |
| notification | a folded paper note | folded corner, app icon as a small seal, urgent = vermilion frame + 印 |
| focus / confirm / urgent | the red seal 印 | `Seal` component — square vermilion, white brush glyph |
| transitions | ink spreading on wet paper | slow ease-outs (`ink`), opacity + 8–16 px translate, no overshoot |

**Signature gesture — the seal (印).** One small vermilion square with a white brush glyph marks: the active
workspace, the confirm button, the right end of every title bar (where the reference had three window dots),
urgent notifications ("imperial order"), and the lock-screen password field. It is the only element allowed
to be *pure* saturated colour at small size; everything else is paper, ink, lacquer and muted mineral pigments.

**Two moods.** `light` = *Apothecary 薬屋* (daytime workbench, rice paper + sumi ink + Maomao's celadon robe).
`dark` = *Inner Palace 后宫* (lacquer night, vermilion, antique gold, jade, paper-cream text). Switch at runtime,
all colours cross-fade in 500 ms.

**Product-name-swap test.** Replace "Apothecary" with any other anime and the paper/ink/seal/drawer system still
fits only if the source world also writes with brushes and stamps with seals — i.e. it does not survive the swap.
The cabinet launcher, 時辰 clock, herb specimen card and the Maomao-green accent are the subject-specific proofs.

**What was sampled.** Maomao's robe in official key art is a *celadon / sage green*, not a blue teal:
anime key art lit #7eba8f–#83bf92, shade #4a7a51–#55945e; LN illustration (Touko Shino) #acd5ae / #4ca07d;
hair #3b4f45 (green-black); hair beads vermilion + teal-blue #67b0be. The accent was refined from these and then
darkened until it passes 4.5:1 on every paper ground (light `#376a4e`) or lightened for lacquer (dark `#7fc19a`).
`accentSoft` keeps the lit robe tone for fills and bars.

**Pairing rule (accessibility):** CJK is decorative. Every CJK label is paired with a Latin meaning
(`TitleBar.subtitle`, tooltip, or `Accessible.name`). Never render meaning in CJK only.

## 5. Motion

Durations: fast 160 · base 350 · slow 600 · theme cross-fade 500 · wallpaper 1200 · stagger 40 (ms).
Easings (Hyprland bezier → QML → CSS):

| name | bezier | QML | CSS | use |
|---|---|---|---|---|
| ink | 0.22, 1, 0.36, 1 | `Easing.OutQuint` | `cubic-bezier(.22,1,.36,1)` | things entering: panels, windows, notes |
| brush | 0.65, 0, 0.35, 1 | `Easing.InOutCubic` | `cubic-bezier(.65,0,.35,1)` | symmetric moves, toggles, cross-fades |
| drift | 0.33, 1, 0.68, 1 | `Easing.OutCubic` | `cubic-bezier(.33,1,.68,1)` | workspaces, hover washes, progress |

What moves:
- Panels (launcher, network, power, wallpapers, notification centre): opacity 0→1 **and** translate 12 px toward their anchor edge, 350 ms `ink`; close 160–250 ms `brush` reversed.
- Notifications: slide 16 px from the right edge + fade, 350 ms `ink`; dismiss slides back 160 ms; stack re-flow 350 ms `drift`.
- Launcher drawers: appear with a **40 ms stagger** per drawer in reading order (opacity + 6 px rise), 350 ms `ink` each; the search drawer first.
- Theme toggle: every colour property 500 ms `OutCubic` (Theme singleton Behaviors); wallpaper `awww` `grow` 1.2 s bezier `.22,1,.36,1` from the mode-toggle button position when known, else centre.
- Hover/pressed washes 160 ms; focus ring instant; seal "stamp" on confirm: scale 1.15→1.0, 160 ms `drift`, then the seal sound.
- OSD: fade + 8 px rise, 160 ms; auto-hide after 1.2 s with 350 ms fade.
- Hyprland: `windowsIn 7 ink popin 85%` · `windowsOut 6 brush popin 85%` · `windowsMove 6 drift` · `fade 5 brush` · `workspaces 8 drift slide` · `layersIn 6 ink slide` · `layersOut 5 brush fade` · `border_angle off` (no rainbow).
- Reduced motion: `config.json {"reduced_motion":true}` → all durations 0 except theme fade 150 ms, no translate, wallpaper `fade` 0.3 s.
- Nothing springs, bounces or overshoots.

Shadow: card `0 4 12 @ shadow` · panel `0 8 24 @ shadowStrong` · note `2 3 6`. Hyprland shadow range 18, render_power 3,
offset 0 3, scale 0.97. Blur (Hyprland layers): size 6, passes 3, vibrancy 0.17, noise 0.02, contrast 0.9, brightness 0.95.
Opacities: transparent card 0.82 · texture overlay light 0.50 · dark 0.45 (tinted tiles*) · ink wash hover 0.08 /
pressed 0.16 · disabled 0.45 · dim_inactive 0.05 · scrim 0.35 · bar 0.92.
*The tinted tiles (`paper-tile.png`, `lacquer-tile.png`) already sit at the surface tone, so the overlay opacity only
scales the grain (`Theme.textureOpacity`). The neutral `*-grain.png` tiles (mean grey) are for Multiply/Overlay
consumers (Hyprland/GTK/CSS) at 15–30 %.

## 9. Accessibility notes

- CJK is never the only carrier of meaning: `TitleBar.subtitle`, `InkButton.text/tooltip`, `Seal.label` and
  `Accessible.name` carry the Latin meaning. Use Simplified forms that the brush fonts actually contain (§3).
- Contrast policy §2.3; text on textured grounds is measured against the flat surface colour — the grain is ≤ ±7/255 and
  the policy keeps ≥ 4.5 with that margin (worst 4.52 on a flat ground; the grain overlay in QML is ≤ 60 % of ±7 ≈ ±4).
- Focus is always visible (1 px seal ring). Hover is never the only state.
- Reduced motion honoured via `config.json`. No flashing; the seal stamp is a single 160 ms scale.
- Minimum hit target 28×28 (bar chips) / 32 (controls) / 44 rows.
- Sounds respect `config.json → {"sounds":false}`; nothing relies on sound.

## 11. How to consume tokens

**QML (Quickshell, config root = `quickshell/`)**
```qml
import qs.Common
PaperPanel { title: "天气"; subtitle: "Weather"; width: 460; height: 300
    InkText { role: "weather_temp"; text: "26°" }
    InkButton { text: "Rescan"; icon: "󰑐"; onClicked: net.rescan() }
}
Rectangle { color: Theme.surfaceAlt; radius: Theme.radius.sm; border.color: Theme.hairline }
Text { font.family: Theme.fontMono; color: Theme.textMuted }          // or InkText { role: "mono"; muted: true }
Image { source: Theme.texture("ground-tile"); fillMode: Image.Tile; opacity: Theme.textureOpacity }
NumberAnimation { duration: Theme.durBase; easing.type: Theme.easeInk }
Theme.setMode("dark"); Theme.toggleMode(); Theme.isDark; Theme.c.seal /* raw "#rrggbb" string */
```
Raw `Theme.c.<role>` strings are CSS `#rrggbbaa`; `Theme.col(role)` / typed properties are Qt-ordered. Use the typed
properties for colours, `Theme.c` only for display/hex labels. `Theme.ready` is true synchronously at startup.

**Hyprland** (`hypr/on.conf`): `source = ~/.config/apothecary/colors.conf` → `tokens/out/<mode>/hyprland-colors.conf`.
It defines `$apo_<role>` for every role, `$apo_ansiN`, `$apo_inkN`, `$apo_paperN`, and already sets
`general:col.active_border` (seal→accent 45deg), `col.inactive_border`, `decoration:shadow:color`, group colours,
`misc:background_color`. Example: `windowrule = bordercolor $apo_accent2, class:^(spf)$`.

**kitty**: `include ~/.config/apothecary/kitty-colors.conf` (→ `tokens/out/<mode>/kitty.conf`, full 16 + fg/bg/cursor/
selection/url/tab/mark/border). Live switch: `kitty @ --to unix:/tmp/kitty set-colors -a -c <file>`.

**GTK 3/4**: `@import url("colors.css");` at the top of `gtk.css` / `gtk-4.0/gtk.css` → `gtk-colors.css` (`@define-color`
with libadwaita + Adwaita names: `window_bg_color`, `view_bg_color`, `accent_bg_color`, `headerbar_bg_color`,
`card_bg_color`, `theme_selected_bg_color` … plus `apo_<role>`). GTK 4.16+ custom properties: `gtk4-vars.css`
(`--apo-<role>`). Keep the two files separate — GTK 3 cannot parse `:root { --x }`.

**rofi**: `@import "colors.rasi"` → `rofi-colors.rasi` defines `* { bg0: …; text: …; seal: …; ansi0..15; ink0..4;
paper0..4; radius-md; frame-width; font-ui; font-title; … }`; use `background-color: @surface;`.

**superfile**: copy/link `superfile-theme.toml` to `~/.config/superfile/theme/apothecary-<mode>.toml` and set
`theme = "apothecary-<mode>"` in `config.toml`. All 38 keys of the v1.5 schema are present (`cursor`, `correct`,
`error`, `hint`, `cancel`, `gradient_color`, panel/sidebar/footer/modal/help_menu groups).

**Others in `tokens/out/<mode>/`**: `qt6ct-colors.conf` (21-colour `[ColorScheme]`, QPalette order), `cava.conf`
(`[color]` section), `btop.theme`, `starship-palette.toml` (`[palettes.apothecary_<mode>]`, `palette = "apothecary_<mode>"`),
`spicetify-color.ini` (`[apothecary_<mode>]`), `zen-vars.css` (`:root --apo-*` + Zen hooks), `nvim-palette.lua`
(`return { … }`), `fastfetch-colors.jsonc` (`display.color` with truecolor SGR), `hyprlock-vars.conf` (`$apo_*` +
`$apo_field_*`, `$apo_font_*`), `wlogout-vars.css`, `palette.json` (flat), `shared.json`, `contrast.md`.

## 12. Quickshell notes (verified on Quickshell 0.3.2)

- `import qs.Common` works when the **config root** (the directory holding `shell.qml`) contains `Common/`.
  Quickshell registers `pragma Singleton` files automatically — no `qmldir` needed. If you do add one, it must list
  **every** file in the directory (Qt then exposes only the listed types).
- A relative `import "../" as Common` from a sub-config does **not** yield singleton instances (you get the type, all
  properties undefined). The preview therefore contains a symlink `quickshell/Common/preview/Common → ..` and imports
  `qs.Common`; the scanner does not recurse into the loop.
- `Quickshell.shellDir` is the config root; Theme resolves the repo as `shellDir/..` (real shell), `shellDir/../../..`
  (preview), `$APOTHECARY_DIR`, `~/.config/apothecary/repo` (symlink that install.sh should create), then
  `~/Projects/apothecary-hyprland`. Reads are synchronous (`FileView.blockLoading`), so no first-frame flash.
- Qt parses 8-digit colours as `#AARRGGBB`; `Theme.qtColor()` converts the CSS-style tokens.
- `MultiEffect` (QtQuick.Effects) is available; shadows are blurred copies of a hidden rect so cards stay interactive.
  Do not hide an interactive item behind a `MultiEffect` (hidden items drop mouse input).
- `console.log` is not shown by `qs`; use `console.warn` while debugging. `Qt.quit()` is ignored.
- Keyboard focus in layer-shell windows needs `WlrLayershell.keyboardFocus: OnDemand` (panels) or `Exclusive` (launcher).
