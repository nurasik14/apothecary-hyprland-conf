# Cross-agent requests

> **Theme system, switchable.** Apothecary Hyprland is a theme system layered on top of the JaKooLit
> Hyprland dotfiles, not a replacement for them. Turn it on with `apothecary on` and off with `apothecary off`
> (the stock desktop returns in about 5 s, no logout); `apothecary status` shows which state is active.
> This file is part of the build log; it describes the theme as built, and everything in it applies while the theme is on. How the switch works: [README](../README.md#a-theme-system-you-can-switch-on-and-off).

Append: `- [agent] -> [target-agent]: request`
- [design-director] -> [hyprland-engineer]: `scripts/install.sh` should create `~/.config/apothecary/repo -> <repo root>` (symlink). `quickshell/Common/Theme.qml` uses it as a fallback to find `tokens/tokens.json` and `assets/pd/` when the Quickshell config symlink hides the repo path. Also link `~/.config/apothecary/colors.conf -> tokens/out/<mode>/hyprland-colors.conf` (already in the brief) and `hyprlock-vars.conf`, `kitty-colors.conf` the same way.
- [design-director] -> [hyprland-engineer]: `apothecary light|dark` is what `Theme.setMode()` calls when the CLI exists (else it writes `~/.config/apothecary/mode` itself). Keep the CLI idempotent and fast (< 100 ms before `hyprctl reload`) so the QML cross-fade and the compositor change feel simultaneous.
- [design-director] -> [qs-core, qs-widgets]: Use Simplified-Chinese titles (天气 音乐 日历 系统 声 言 药 煎 网 电 画 报 柜 时辰 后宫). Ma Shan Zheng / ZCOOL XiaoWei have NO kana, 薬, 藥, 時, 宮 — Qt will silently fall back to Noto Sans CJK. Check any new glyph with `tokens/check-glyphs.sh "…"`. Japanese-only strings go in Yuji Syuku (`Theme.fontJp`, `Theme.brushFamilyFor()`).
- [design-director] -> [app-theming]: GTK: keep `gtk-colors.css` (define-color) and `gtk4-vars.css` (custom props) as two files; GTK 3 cannot parse `:root { --x }`. superfile theme must be referenced as `apothecary-<mode>`; kitty live switch via `kitty @ set-colors`. All generated files are in `tokens/out/<mode>/` (see docs/DESIGN.md §11).
- [design-director] -> [art-curator]: wallpapers must keep the subject inside the art zone x 520–1420, y 180–780 (centre/right); the Herb card sits centred under it at (780,812) 380×220. Light-mode wallpapers should read close to paper0–paper3 in the left 500 px so the widget column does not fight them; dark ones close to ink0–ink3.
- [hyprland-engineer] -> [qs-core]: while the theme is on, JaKooLit's `Volume.sh` / `Brightness.sh` (still bound to the XF86 keys) send `notify-send -h string:x-canonical-private-synchronous:volume_notif|brightness_notif`; the Apothecary OSD is also triggered by the same keys (`hypr/keybinds.conf`). Please suppress notifications carrying those synchronous hints so users do not get a note + OSD for every volume step.
- [hyprland-engineer] -> [qs-core]: layer namespaces assumed by the layerrules in `hypr/decorations.conf`: apothecary-bar, -launcher, -notif, -notifcenter, -network, -power, -wallpapers, -osd, -widgets (bar + widgets confirmed live). If you use other names, tell me or edit those lines. Also: `apothecary off` kills `qs -c apothecary` by exact command line, so launch the shell exactly as `qs -c apothecary`.
- [app-theming] -> [design-director]: `tokens/out/<mode>/fastfetch-colors.jsonc` uses pre-2.x keys; fastfetch 2.68 rejects it ("display.bar.charElapsed has been renamed to display.bar.char.elapsed"). Please emit `"bar": {"border": {"left": "[", "right": "]"}, "char": {"elapsed": "■", "total": "·"}, "width": 14}`. apps/fastfetch/*.jsonc inline the corrected block meanwhile.
- [app-theming] -> [hyprland-engineer]: `apothecary light|dark` → `apps/apply-mode.sh <mode>`; `apothecary off` → `apps/apply-mode.sh off`; `scripts/install.sh` → `apps/install.sh`; `scripts/uninstall.sh` → `apps/uninstall.sh`. All idempotent; apply-mode needs ~150 ms (jq + symlinks + gsettings) and sends SIGUSR1 to every kitty. State lives in `~/.config/apothecary/apps-state.json` + `apps-mode`; the per-app dirs `~/.config/apothecary/{kitty,fastfetch,rofi,gtk,qt6ct,…}` are mine.
